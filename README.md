# Birthday Surprise — Flask Project

A small interactive birthday website made with Python + Flask.

## Run locally

1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Start the website:

```bash
python app.py
```

5. Open the local address shown in the terminal, usually:
`http://127.0.0.1:5000`

## Personalize it

Open `templates/index.html` and search for:
- `[HER NAME]`
- `[YOUR NAME]`
- `your favorite line`

You can replace those with your own text.

The project uses no external images and needs no database.
